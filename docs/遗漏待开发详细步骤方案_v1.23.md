## 4. MDK 内核统一 · 修复开发详情方案（M1~M4）

### 4.1 现状：接缝已现成，MDK 是「插入」而非「重写」

现有播放内核是一套「**后端枚举 + 降级链 + 统一 MethodChannel + 统一 Flutter 纹理输出面**」：

| 层 | 落点 | 现状 |
|---|---|---|
| 后端枚举 | [player.dart](../lib/domain/entities/player/player.dart#L10-L49) | `PlayerBackend { media3, libVLC, libmpv, nativeiOS }` + `displayName` / `shortName` / `supportsSystemPip` |
| 平台链 | [player.dart](../lib/domain/entities/player/player.dart#L214-L229) | Android `[media3, libVLC]` · Windows/macOS `[libmpv]` · iOS `[nativeiOS]` |
| 回退判定 | [player.dart](../lib/domain/entities/player/player.dart#L234-L243) | `needsFallback`：`.mkv/.flv/.ts/.rmvb/.avi/.wmv/.m2ts` → 全格式后端 |
| 编排 | [player_controller.dart](../lib/platform/player/player_controller.dart#L183-L223) | `_openWithChain`：逐后端试 → 失败降级（`onBackendFallback` 可观测） |
| 通道值 | [player_channel_bridge.dart](../lib/platform/player/player_channel_bridge.dart#L14-L19) | `backendWireValue`：enum → 原生字符串 |
| 通道 | [channel_player.dart](../lib/platform/player/channel_player.dart#L70-L83) | `open` 传 `backend` + 取回 `textureId` |
| 原生 | [PlayerPlugin.kt](../android/app/src/main/kotlin/com/vbox/player/PlayerPlugin.kt) / [player_plugin.cpp](../windows/runner/player_plugin.cpp) / [PlayerPlugin.swift](../macos/Runner/PlayerPlugin.swift) | Android：ExoPlayer + libVLC；Windows：libmpv；macOS：AVPlayer + libmpv；**均写同一 Flutter 纹理** |

> **结论**：MDK 只需在**同一接缝**上新增一个后端实现，**控制层 / UI / 播放页零改动**。

### 4.2 M1 · Dart 侧接入（纯 Dart，可立即交付、零风险）

**目标**：把 MDK 纳入后端枚举与降级链；原生未接入时行为与现状完全一致。

| # | 步骤 | 落点 |
|---|---|---|
| 1 | `PlayerBackend` 新增 `mdk`，并补 `displayName='MDK（全格式）'` / `shortName='MDK'` / `supportsSystemPip=true` | [player.dart](../lib/domain/entities/player/player.dart#L10-L49) |
| 2 | `backendWireValue` 补 `PlayerBackend.mdk => 'mdk'` | [player_channel_bridge.dart](../lib/platform/player/player_channel_bridge.dart#L14-L19) |
| 3 | `chainFor` 调链：Android `[media3, mdk, libVLC]`；Windows/macOS `[mdk, libmpv]` | [player.dart](../lib/domain/entities/player/player.dart#L214-L229) |
| 4 | `selectInitialBackend`：需全格式（复杂封装 / FLV 直播）→ **MDK 优先**，无 MDK 再降 VLC/mpv | [player_controller.dart](../lib/platform/player/player_controller.dart#L53-L65) |
| 5 | 内核面板自动出现 MDK 项（数据源即 `availableBackends`，**无需改 UI**） | 自动 |

**验收 / 单测**：
- `chainFor` 三端链断言（含 `mdk` 位置）；
- `selectInitialBackend` 优先级：`.mkv` → `mdk`；`.mp4` → 链首（`media3`）；
- **降级链回归**：原生未接 MDK → `open(backend:'mdk')` 回 `E_BACKEND_UNAVAILABLE` → 自动降级到 `libVLC`/`libmpv`（用 fake bridge 断言降级事件序列）。

> **风险**：无。未接原生时 MDK 恒不可用，仅多一次失败的 open 尝试（与现有 `media3→libVLC` 降级同形）。
